## 技术笔记

### CSS 内联解析器 bug 点
- `parse_tag` 中 `</style>` 被错误解析为 `tag='style', end=<wrong>`
- 原因：检测条件 `html[i+1]=='/' and html[i+2]=='>'` 不适用于 `</style>`（后面是 `s` 不是 `>`）
- 修复已在代码中（`k = j + 1; while k < len(html) and html[k] != '>'`），但 `inline_css` 主循环对闭合标签的处理可能还有漏网之鱼

### exec 写文件方法（可靠）
- 用 `printf` + heredoc：`printf '%s\n' 'line1' 'line2' > file`
- 用 `python3 -c "open('f','w').write(...)"` — 单行 Python 写文件
- `write` tool 有 bug（Missing required parameter: path），避免使用
