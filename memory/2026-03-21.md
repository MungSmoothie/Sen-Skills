## 科幻片 Top10 HTML 页面

- 今日完成：2025 科幻电影精选 Top10 HTML 页面（scifi_top10.html）
- 需求来源：绿豆冰沙（大哥）
- 技术方案：
  1. 先用 Douban API 拉取科幻片数据（tag=科幻，按时间排序）
  2. Douban 不收录 2025 年新片（数据库最新到 2024），改为以豆瓣评分 7+ 科幻片为准
  3. IMDB poster 图片也无法直接嵌入 Telegram（Telegram 限制 base64 inline image）
  4. 最终方案：**IMDB CDN 图片下载到本地 → 转 base64 嵌入 HTML → 作为 HTML 文件发送**
- 封面获取方式：
  - Douban API `/j/subject_abstract` 返回电影基本信息（标题、年份、评分、导演、类型）
  - Douban 图片 CDN（img1/9.doubanio.com）被 Telegram 拦截（返回 418 状态码）
  - IMDB poster CDN（m.media-amazon.com）**部分可访问**（Inception/WALL-E 可通，其他返回 9 bytes）
  - **IMDB suggestion API** `https://v2.sg.media-imdb.com/suggestion/x/{movie}.json` 可获取所有电影的正确 poster URL
  - 用该 API 获取了 10 部豆瓣高分科幻片的 IMDB poster URL
- 总耗时：约 2 小时（研究封面方案占用大量时间）
- 最终 HTML 大小：约 1653KB（封面 base64 占大头）
- 文件路径：`/home/claw/.openclaw/workspace/scifi_top10.html`
- 发送成功（messageId: 3825）

## IMDB Poster 抓取技巧

IMDB poster URL 格式：`https://m.media-amazon.com/images/M/{code}._V1_.jpg`
获取方式：用 `https://v2.sg.media-imdb.com/suggestion/x/{query}.json` API 查询，response 的 `d[].i.imageUrl` 即为 poster URL。

注意：IMDB poster URL 中若有 `_FMjpg_` 字样会返回 9 bytes（Not Found），去掉 `_FMjpg_UX500_` 部分才能正常下载。
