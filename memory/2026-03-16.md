### 技能功能
生成横版AI日报，包含：
- 5个可点击切换频道：今日要闻、深度报道、国际焦点、科技前沿、财经观察
- 头条区：标题+副标题+摘要+数据条+延伸分析+二狗点评
- 右侧边栏：快讯+股市+金句+治愈+笑料
- 底部4-8条新闻卡片

### 核心规则
1. **新闻必须真实**：生成前先联网搜索，使用36氪、品玩、机器之心等来源
2. **每个频道都要完整**：不能只写"整理中"
3. **每个频道都要有二狗点评**
4. **治愈/笑料用API获取**

### API 配置
- 笑话API: `curl -s "https://api.timelessq.com/joke?level=5"`
- 治愈API: `curl -s "https://api.mir6.com/api/yulu?txt=8&type=json"` (txt=1安慰语录, txt=8温柔文案)
