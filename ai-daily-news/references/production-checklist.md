# Production Checklist

生成日报时按此清单执行，形成闭环。

## 1. 搜集
- 搜集当天或最近几天的真实新闻。
- 至少为五个频道各准备 1 个头条角度。
- 同时准备快讯、市场数据、句摘、笑料。

## 2. 筛选
- 去掉明显过旧、重复、不可证实的内容。
- 优先保留官方来源与高可信媒体。
- 选出最适合放在“今日要闻”的头条。

## 3. 分配
- 将不同新闻分配到五个频道。
- 确保五个频道不是同一标题反复改写。
- 为每个频道准备：摘要、4-5 个数据点、3 个延展信息、1 条点评、4 条底部补充新闻。

## 4. 填槽
- 使用 `assets/template.html`。
- 使用 `assets/style.css`。
- 参考 `references/slot-map.md` 填充占位符。
- 不改 DOM 层级，不改频道顺序，不改 CSS 变量。

## 5. 自检
- 是否所有事实都可验证？
- 是否所有频道都完整？
- 是否仍是同一套报刊风格？
- 是否出现了占位文本或假数据？
- 是否只准备输出 HTML？

## 6. 输出
- 只输出完整 HTML。
- 不附解释。
