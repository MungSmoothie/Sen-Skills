# 生产检查清单

本文件用于在输出最终 HTML 之前，做一次完整自检。

## 一、版式检查
- 是否仍然是中文报刊 / 杂志社风格？
- 是否避免了科技门户、dashboard、博客卡片流的视觉感？
- 是否保持暖白 / 米白底？
- 是否保留报头、细导航、主头条双栏、右侧窄栏、底部四栏、页脚？
- 是否仍然沿用固定模板和主样式？
- 是否没有新增一级模块、改变主副栏比例、把四栏改成卡片流？

## 二、内容检查
- 主头条是否真实、重要、适合做整版中心？
- 副标题与摘要是否交代背景、变化和影响？
- 数据带数字是否都可验证？
- 延展模块是否真的补充了影响 / 背景 / 看点？
- 二狗点评是否像编辑部点评，而不是段子或营销文案？
- 今日快讯是否与主头条避免重复？
- 市场脉搏是否没有假数字、假幅度、假估值？
- 每日治愈 / 每日笑料是否轻量且不冒犯？
- 底部四栏是否各栏独立、不重复主头条？

## 三、来源检查
- 主头条是否至少完成双来源交叉验证？
- 如果只有一个来源，它是否为一手信源？
- 所有量化信息是否都有可验证依据？
- 是否优先使用了更高等级来源？
- 是否尽量回溯了英文原始来源？
- 是否没有把论坛传闻、匿名爆料、截图、自媒体搬运当成主依据？

## 四、去重检查
- 是否没有同一事件在多个频道机械重复做头条？
- 今日快讯是否没有重复主头条核心事实？
- 底部四栏是否没有写成同一事件的四种说法？
- 若同一主题跨频道出现，是否真的换了视角？

## 五、模板检查
- 是否优先使用了 `assets/template.html`？
- 是否优先使用了 `assets/style.css`？
- 是否只是替换槽位，而不是重写页面？
- 是否没有改 class 命名、模块层级、栏目位置？
- 是否通过调节文案长度适配版面，而不是改布局？

## 六、输出检查
- 是否最终只输出完整 HTML？
- 是否没有混入 markdown 解释？
- HTML 是否完整、结构闭合、样式引用正确？
- 若任一项不满足，应先修正，再输出。
