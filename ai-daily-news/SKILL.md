# AI Daily News Generator

生成日报时，先保证**真实性**，再保证**模板一致性**，最后输出**完整 HTML**。本 skill 不是“从零自由发挥做网页”，而是“把真实新闻填进固定报刊模板”。

## 最高优先级规则

1. **新闻和数据必须真实。** 先检索真实、近期、可验证的新闻与市场数据，再开始写页面。不得编造新闻、股价、公司动作、人物言论、发布时间。
2. **模板必须优先。** 若 `assets/template.html` 和 `assets/style.css` 存在，必须优先复用它们；除非用户明确要求改版，否则只替换内容，不重写结构与样式。
3. **输出必须闭环。** 生成前完成搜集、筛选、分配、填槽、自检；输出时只给完整 HTML，不给解释、步骤说明、Markdown、占位文本。

## 固定工作流（必须按顺序）

1. 搜索当天或最近的真实 AI / 科技 / 国际 / 财经新闻。
2. 选出每个频道的头条与补充新闻，避免五个频道都在重复同一件事。
3. 补充真实市场数据与可验证的引用信息。
4. 按 [references/slot-map.md](references/slot-map.md) 将内容填入固定槽位。
5. 基于 `assets/template.html` 与 `assets/style.css` 生成最终页面。
6. 按“输出前自检清单”检查一遍。
7. 只输出完整 HTML。

## 模板优先原则

### 必须遵守
- 以 `assets/template.html` 作为唯一母版。
- 以 `assets/style.css` 作为唯一基础样式。
- 默认只替换占位符，不改 DOM 层级，不改模块顺序，不改主副栏比例，不改 CSS 主变量。
- 若当天内容不足，允许压缩文案长度，但**不允许**删除一级模块。

### 只有在以下情况才允许改动模板
- 用户明确要求“改版”“换风格”“重做结构”“新增栏目”。
- 用户明确要求更换报头、频道数、左右栏比例或视觉语言。

若没有上述明确要求，必须保持“村口情报社”报刊风格稳定一致。

## 固定视觉语言（必须保持一致）

### 页面气质
- 必须是中文报刊 / 杂志社排版，不是科技门户、博客首页或 dashboard。
- 分组依靠细分隔线、留白、字号层级、栏宽，不依靠卡片感组件。
- 风格关键词：纸张感、编辑部、专栏页、高信息密度、克制。

### 配色
- 页面底色固定为暖白、米白、浅纸张色。
- 主文字固定为黑色或深灰。
- 强调色固定为暗红、酒红、棕红中的一种，仅小面积使用。
- 禁止大面积纯黑顶栏、荧光色、霓虹色、渐变背景、鲜红整块导航。

### 组件限制
- 禁止圆角卡片、阴影卡片、浮层、按钮式模块、瀑布流、产品卡片墙。
- 禁止把页面做成后台面板或资讯门户首页。
- 禁止因新闻数量变化而改变整体版式节奏。

### 字体与层级
- 报头、频道标题、头条标题必须有明显层级差异。
- 主标题显著大于副标题与正文。
- 英文标签、栏目小标题可以克制，但不能抢主标题视觉中心。

## 固定页面结构（默认不可改）

页面结构必须始终保持以下顺序：

1. **报头**
   - 左：刊名、英文副标、身份说明
   - 右：日期、期数、编辑、原创说明
2. **顶部细导航**
   - 五个频道文字导航
   - 支持点击切换
3. **频道主区**
   - 左侧宽栏：英文小标签、头条标题、副标题、摘要正文、数据带、延展信息、二狗点评
   - 右侧窄栏：今日快讯、市场脉搏、每日治愈、每日笑料
4. **底部新闻区**
   - 固定四栏新闻块
5. **页脚**
   - 刊名 / 联系方式 / 投稿信息 / 原创整理标识

## 固定频道与内容要求

### 五个频道（固定存在）
1. 今日要闻
2. 深度报道
3. 国际焦点
4. 科技前沿
5. 财经观察

### 每个频道必须包含
1. 英文或风格化小标签
2. 头条标题
3. 副标题
4. 摘要正文（建议 120-320 字）
5. 核心数据带（固定 4-5 个）
6. 延展信息块（固定 3 个，若不足则缩短文案但保留结构）
7. 二狗点评（必须有）
8. 右侧边栏四模块（必须有）
9. 底部四条相关新闻（必须有）

### 内容分配规则
- “今日要闻”放当天最重要、最泛化的头条。
- “深度报道”放机制解析、技术大会、研究进展、框架变更。
- “国际焦点”放海外公司、海外政策、国际产业趋势。
- “科技前沿”放新品、展会、应用发布、开发者工具。
- “财经观察”放股价、融资、财报、资本市场与商业影响。

不同频道允许围绕同一大主题，但头条角度必须不同，不能只是改标题重复。

## 侧栏规则（固定四模块）

### 今日快讯
- 5-7 条简讯。
- 每条必须来自真实新闻。
- 文案短、密、可扫描。

### 市场脉搏
- 展示真实可验证的数据。
- 优先选择与当天页面主题高度相关的公司或指数。
- 若拿不到盘中数据，可使用最近收盘数据或明确可验证的价格 / 涨跌幅。
- 不得虚构涨跌。

### 每日治愈
- 1 条简短句摘。
- 风格克制，不煽情过度。

### 每日笑料
- 1 条轻松短笑话。
- 不低俗，不与严肃新闻冲突。

## 数据带规则

- 数据带固定 4-5 项。
- 优先使用最能支撑头条的事实数据，不要堆空泛词。
- 可以使用：模态数、上下文长度、发布时间、地区、融资额、涨跌幅、排名、模型维度、用户数、门店数等。
- 呈现方式必须像“报刊信息带”，不是 KPI 仪表盘。

## 二狗点评规则

- 每个频道必须有“二狗点评”。
- 语气像懂行业但接地气的编辑点评。
- 可以有轻微口语化，但不能写成网络段子合集。
- 必须建立在真实新闻之上，不能脱离事实乱发挥。
- 建议长度 60-140 字。

## 搜索与选材规则

### 优先来源
优先使用权威、公开、可验证来源，例如：
- 公司官网 / 官方博客 / 官方新闻稿
- 主流科技媒体
- 主流财经媒体
- 可信行业媒体

### 选材要求
- 优先选“当天”或“最近几天”的内容。
- 若当天高质量新闻不足，可回退到最近一周，但不要混入明显过旧内容。
- 若来源冲突，优先官方或更高可信度来源。
- 不得因为搜不到就填“整理中”“略”“待补充”。

## 输出约束

生成时必须满足以下要求：

1. 输出是**完整可运行 HTML**。
2. 包含顶部导航 JS 切换逻辑。
3. 包含五个频道完整内容。
4. 保持 `assets/template.html` 的整体结构和 `assets/style.css` 的整体设计语言。
5. 页脚保留原创整理与身份说明。
6. 日期格式使用中文完整日期，例如：`2026年3月16日 星期一`。
7. 编辑信息使用报刊体例，例如：`总第47期 · 编辑：二狗 绿豆冰沙`。
8. 不输出代码块围栏，不输出“下面是 HTML”。

## 明确禁止项

禁止出现以下任一情况：
- 科技门户首页风格
- dashboard / 后台面板风格
- 大面积黑底 + 鲜红导航条
- 圆角卡片、阴影卡片、按钮式模块
- 底部做成产品卡片墙或瀑布流
- 随意新增 / 删除一级模块
- 使用占位文本、假链接、假数据
- 虚构新闻、虚构股价、虚构时间线、虚构引用
- 为了“更好看”而脱离模板自由改版

## 输出前自检清单

输出前必须检查：

- 新闻是否真实、近期、可验证？
- 市场数据是否真实？
- 是否仍然是同一套“村口情报社”报刊模板？
- 是否误用了门户站 / dashboard / 卡片流风格？
- 五个频道是否都完整？
- 每个频道是否都有二狗点评？
- 右侧边栏四模块是否都存在？
- 底部是否固定为四栏新闻区？
- 是否只输出 HTML？
