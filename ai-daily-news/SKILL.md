# AI Daily News Generator

生成日报时，优先保证 **真实性** 与 **版式一致性**。

## 最高优先级规则

1. **新闻必须真实、可验证、尽量新。** 先搜索真实新闻与真实市场数据，再写页面内容，不得编造新闻、股价、时间、公司动作、人物言论。
2. **版式必须稳定。** 除非用户明确要求“改版 / 换风格 / 重做样式”，否则只更新内容，不重做页面结构，不切换视觉风格。
3. **输出必须是完整 HTML。** 不输出解释，不输出 markdown，不输出“整理中”“待补充”“示例内容”等占位文本。

## 固定视觉语言（必须遵守）

必须稳定输出“村口情报社”式中文报刊页面，视觉上接近高信息密度的报纸 / 杂志社专栏页，而不是科技门户、博客首页或 dashboard。

### 配色
- 页面底色固定为暖白、米白或浅纸张色。
- 主文字颜色固定为黑色或深灰。
- 强调色固定为暗红、酒红、棕红中的一种，仅用于小面积点缀。
- 禁止使用大面积纯黑顶栏、鲜红整块导航、霓虹色、渐变背景。

### 版式气质
- 必须呈现“报刊排版感”，而不是“UI 卡片感”。
- 分组主要依靠：细分隔线、留白、字号层级、栏宽。
- 禁止圆角卡片、阴影、按钮式模块、悬浮组件、强烈产品后台风格。

### 字体与层级
- 主标题必须具有中文报刊头条气质，显著大于其余文字。
- 标题倾向使用衬线风格；正文倾向使用宋体 / 衬线风格或与之接近的字体回退。
- 小标题、栏目标签、英文副标可更克制，不得喧宾夺主。

## 固定页面结构（默认不可改）

页面结构必须稳定为以下顺序：

1. **报头**
   - 左侧：刊名“村口情报社”或等价报头
   - 下方：英文副标 / slogan
   - 右侧：日期、星期、总第几期、编辑信息

2. **细导航栏**
   - 仅文字型频道导航
   - 可点击切换频道
   - 禁止按钮型大色块导航

3. **主内容区：双栏结构**
   - 左侧宽栏：头条、摘要正文、数据带、延展信息、点评
   - 右侧窄栏：今日快讯、市场脉搏、今日句摘 / 每日治愈、今日笑料

4. **底部新闻区**
   - 固定 4 栏报刊式新闻块
   - 每栏顶部使用细横线或细分隔
   - 禁止瀑布流、卡片瀑布、宫格产品卡片样式

5. **页脚**
   - 刊名 / 联系方式 / 投稿信息 / 原创整理标识

## 固定栏目与内容槽位

### 五个频道（固定存在）
1. 今日要闻 - 综合头条
2. 深度报道 - 长文分析 / 技术大会
3. 国际焦点 - 国际新闻 / 行业趋势
4. 科技前沿 - 产品发布 / 展会报道
5. 财经观察 - 股价 / 市场分析

### 每个频道的固定结构
每个频道都必须包含以下内容槽位，顺序保持一致：

1. 频道标签 / 英文小标签
2. 头条标题
3. 副标题
4. 摘要正文（基于真实新闻，建议 120-320 字）
5. 核心数据带（固定 4-5 个指标）
6. 延展信息块（如技术亮点 / 应用落地 / 影响评估）
7. 二狗点评（每个频道都必须有）
8. 右侧边栏（快讯 / 市场 / 治愈 / 笑料）
9. 底部 4 条相关新闻

## 右侧边栏规则（固定存在）

右侧边栏必须包含以下模块，并保持窄栏排版：

1. **今日快讯**
   - 5-7 条
   - 简洁时间轴或简讯列表风格
   - 每条必须对应真实新闻

2. **市场脉搏**
   - 使用真实涨跌数据
   - 优先选择与当天主题相关的公司 / 指数
   - 若无法获得精确盘中价格，可写收盘价或最近可验证价格，但不得编造

3. **今日句摘 / 每日治愈**
   - 1 条即可
   - 风格简短克制

4. **今日笑料 / 每日笑料**
   - 1 条即可
   - 适合日报氛围，不低俗

## 内容生成流程（必须按顺序）

1. 先搜索当天或最近的真实 AI / 科技 / 财经新闻。
2. 交叉核对新闻事实，优先选择可信来源。
3. 再补充真实市场数据。
4. 将内容分配到固定频道与固定槽位。
5. 使用固定报刊模板组织页面。
6. 最后输出完整 HTML。

不得在生成 HTML 的过程中临时更换布局、颜色体系、模块层级或频道顺序。

## 搜索与选材规则

### 推荐来源
优先从权威、公开、可验证来源选材，例如：
- 公司官方博客 / 官方新闻稿
- 主流科技媒体
- 主流财经媒体
- 可信行业媒体

### 选材原则
- 当天最重要的新闻放入“今日要闻”头条。
- 不同频道的主头条尽量避免高度重复。
- 深度报道优先选技术机制、模型更新、产业趋势。
- 财经观察必须体现资本市场或商业影响。

## 数据带规则

核心数据带固定为 4-5 项，风格统一，适合报刊信息带，不要做成 KPI 仪表盘。

可选内容包括：
- 模态数量
- 参数区间
- token 上下文
- 排名 / 基准结果
- 发布时间
- 涉及公司数
- 涨跌幅
- 融资额

## 二狗点评规则

- 每个频道都必须有“二狗点评”。
- 语气要像懂行业、略带口语的编辑点评。
- 可以有观点，但必须建立在真实新闻之上。
- 不要写成社交媒体段子，不要过度夸张。
- 点评篇幅建议 60-140 字。

## 模板优先原则

如果用户已经提供既有 HTML 模板、参考截图或目标版式：

- 优先复用其结构与视觉语言。
- 用户未明确要求改版时，只替换内容，不重写布局。
- 内容更新不应导致模块位置、颜色体系、字号体系、DOM 层级发生明显变化。
- 同一技能多次生成时，应尽量复用同一套 class 命名、布局方式与样式节奏。

## 明确禁止项

禁止出现以下情况：
- 科技门户首页风格
- dashboard / 后台面板风格
- 大面积黑底 + 红色导航条
- 圆角卡片、阴影卡片、按钮式模块
- 因当天新闻数量变化而随意增删一级模块
- “整理中”“稍后补充”“示例新闻”等占位内容
- 虚构新闻、虚构股价、虚构时间线、虚构 quote
- 把底部新闻区做成产品卡片墙

## 输出要求

直接输出完整 HTML 代码，并满足以下要求：

1. 包含可点击的频道导航（JS 切换内容）。
2. 包含 5 个频道的完整内容。
3. 每个频道都必须有：头条、副标题、摘要正文、数据带、延展信息、二狗点评、右侧边栏、底部 4 条新闻。
4. 页面整体视觉必须保持固定报刊风格。
5. 页脚必须包含“AI资讯整理 · 行业信息速览”与“@来一杯绿豆冰沙 · 原创整理”一类原创标识。
6. 日期格式使用中文完整日期，例如：`2026年3月16日 星期一`。
7. 编辑信息保持报刊体例，例如：`总第47期 · 编辑：二狗 绿豆冰沙`。

## 稳定性检查清单

输出前必须自检：

- 新闻是否真实、近期、可验证？
- 市场数据是否真实？
- 是否仍然是同一套报刊版式？
- 是否误用了门户站 / dashboard / 卡片流风格？
- 是否五个频道都完整？
- 是否每个频道都有二狗点评？
- 是否右侧边栏四个模块都存在？
- 是否底部固定为 4 栏新闻区？
- 是否只输出 HTML？
