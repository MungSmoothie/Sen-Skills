# AI Daily News Generator

⚠️ **核心原则：新闻必须真实、实时！**

生成日报前必须先联网搜索真实新闻素材，不能编造新闻。

## 搜索新闻渠道
- 36氪 (https://www.36kr.com/information/AI/)
- 品玩 (https://www.pingwest.com/)
- 机器之心 (https://www.jiqizhixin.com/)
- 澎湃新闻 (https://www.thepaper.cn/)
- 新浪财经 (https://finance.sina.com.cn/stock/)

## 搜索要求
1. 先搜索获取当日真实AI/科技/财经新闻
2. 筛选有价值的热点内容
3. 获取真实的股价数据
4. 每个频道都要有详细内容，不能只写"整理中"
5. 每个频道都要有二狗点评
6. 再开始生成日报

## 内容结构

### 五个频道（可点击切换）
1. 今日要闻 - 综合头条（必须放当天最重要的真新闻）
2. 深度报道 - 长文分析/技术大会
3. 国际焦点 - 国际新闻/行业趋势
4. 科技前沿 - 产品发布/展会报道
5. 财经观察 - 股价/市场分析

### 每个频道的完整结构
- 频道标签 + 头条标题 + 副标题
- 摘要正文（基于真实新闻，100-300字）
- 核心数据带：4-5个数据指标
- 二狗点评（每个频道都要有！）
- 右侧边栏：快讯/市场/治愈/笑料
- 底部4条新闻卡片

### 右侧边栏（必须包含）
- 今日快讯（时间轴样式，5-7条）
- 市场脉搏（真实涨跌数据）
- 每日治愈（从API获取）
- 每日笑料（从API获取）

## API调用

### 治愈/语录API
```bash
# txt=1: 安慰语录, txt=5: 励志, txt=8: 温柔文案, txt=11: 人生话语
curl -s "https://api.mir6.com/api/yulu?txt=11&type=json"
```

### 笑话API
```bash
curl -s "https://api.timelessq.com/joke?level=5"
```

## 抖音发布标识
发抖音时必须包含以下标识：
- 身份说明：`📱 AI资讯整理 · 行业信息速览`
- 原创标识：`@来一杯绿豆冰沙 · 原创整理`

## 输出要求

直接输出完整HTML代码，包含：
1. 顶部可点击导航（JS切换内容）
2. 5个频道的完整内容（每个频道都有头条+点评+侧边栏+4条卡片）
3. 头条区完整结构
4. 右侧边栏5个模块（快讯+市场+治愈+笑料）
5. 底部新闻卡片
6. 底部页脚
