小米发布 MiMo-V2-Pro：1万亿参数逼近 GPT-5.2，成本仅为七分之一

DeepSeek R1 核心成员领衔研发，1M 上下文窗口刷新中国大模型性能纪录

小米于3月21日发布 MiMo-V2-Pro，1万亿参数大模型在 Artificial Analysis 全球智能指数位列第10，接近 GPT-5.2 与 Claude Opus 4.6 水平，但 API 调用成本仅约 4美元/百万token，约为 GPT-5.2 的七分之一。该模型由前 DeepSeek R1 核心成员 Fuli Luo 主导，采用稀疏架构（42B 活跃参数），结合 7:1 混合注意力机制，实现100万上下文窗口。研究机构已验证该模型幻觉率降至30%，并预告将开源部分版本。

架构亮点

采用稀疏架构：1T总参中仅42B活跃；7:1混合注意力比（处理85%数据时"速览"，15%高密度注意），配合多Token预测层降低推理延迟。

Benchmark 验证

Artificial Analysis 确认：全球智能指数第10位，与 GPT-5.2 Codex 同档；在 GDPval-AA（真实任务代理评测）中超越 GLM-5 与 Kimi K2.5。

Fuli Luo 在 X 平台透露，模型稳定后将开源部分变体。小米正从消费硬件公司向"具身智能+大模型"垂直整合企业转型。

深度

从 Vera Rubin 看 Nvidia 的 Agent 时代赌注：硬件公司还是软件平台？

7芯片平台背后的战略逻辑：为什么黄仁勋说"聊天机器人时代已经结束"

GTC 2026 上 Nvidia 发布的 Vera Rubin 不仅仅是一代新硬件。7枚芯片联合、5个机架级系统合一、从 GPU 到 CPU 到 LPU 到 DPU 全链路覆盖——这意味着 Nvidia 正在将自身定位从"AI 芯片供应商"向"AI 基础设施操作系统提供商"迁移。本次 GTC 的核心叙事是"Agentic AI 临界点已至"，而 Nvidia 的所有产品线——Vera Rubin、NemoClaw、Dynamo 1.0、Nemotron Coalition——都在围绕这一判断展开布局。

为什么是"7"枚芯片

Agentic AI 的工作负载不再单一：CPU 执行沙盒代码、GPU 推理、长程上下文需要 KV 缓存存储、Groq LPU 负责低延迟 token 生成、Ethernet 互联成瓶颈——没有一枚芯片能覆盖全链路，7芯片联动是架构刚需而非营销数字。

Dynamo 1.0 的战略价值

Dynamo 被 Nvidia 定位为"AI 推理工厂操作系统"，已获 AWS/Azure/GCP/Oracle/Cursor/PayPal/Pinterest 部署。它解决的不仅是 GPU 调度，而是分布式推理工厂层面的资源弹性——这是未来 AI 计算量贩化的基础设施。

Nemotron Coalition 的生态意图

开源 Frontier 模型一方面培养开发者生态对 Nvidia 硬件的依赖，另一方面也避免 Nvidia 与顶级实验室直接竞争。Mira Murati 新创立的 Thinking Machines Lab 加入 coalition，是值得关注的信号。

📣 二狗点评

俺观察 Nvidia 好几年了，这波操作比往年任何一次发布都激进。以前老黄卖的是"更强的卡"，这次卖的是"一整套 Agent 时代的工作站"。这背后的判断是：聊天 AI 的计算模式是一次性的，Agent AI 的计算是连续的、长期的、跨模态的。对俺们搞情报的人来说，关键是盯紧 Cursor、Perplexity 这些已经在用 Dynamo 的公司——它们的成本曲线会最先改善。

Cursor Composer 2 评测：编程模型价格战的引爆点

Fine-tuned 版 Kimi K2.5，降价86%，能否对抗 OpenAI Codex 与 Claude Code 的夹击？

Cursor 发布 Composer 2，这是其首款完全自研的编程模型，基于 Kimi K2.5 微调而来。定价从 Composer 1.5 的 $3.50/$17.50（输入/输出每百万token）直接降至 $0.50/$2.50，降幅达86%。Benchmark 方面，Composer 2 在 SWE-bench Multilingual 达73.7分，Terminal-Bench 2.0 达61.7分，超越 Claude Opus 4.6（58.0），但仍小幅落后于 GPT-5.4（75.1）。Cursor 估值29.3亿美元，正面临 OpenAI Codex 与 Anthropic Claude Code 的双向竞争。

技术细节

Composer 2 采用继续预训练+规模化强化学习路线，首次利用长期代理编程任务数据进行训练，支持20万token上下文，可调用 Cursor 完整工具栈（语义搜索、文件编辑、Shell命令、浏览器控制）。

竞争格局

Claude Code 以"terminal-first"工作流吸引高端用户；OpenAI Codex 背靠 GPT-5 能力；Cursor 则试图以平台整合+低价策略守住中间市场。

锁定争议

Composer 2 为 Cursor 专有模型，不通过外部 API 分发，也不提供通用可部署权重——这是竞争优势，也是用户粘性的双刃剑。

📣 二狗点评

Cursor 这波降价挺猛的，但俺觉得它的护城河不是模型本身，而是那个编辑器。Composer 2 降价86%听起来很香，但用户真正绑定的还是 Cursor 的 agent 工具链和团队协作功能。就跟俺村的剃头匠一样——推子便宜不重要，手艺好才是关键。
