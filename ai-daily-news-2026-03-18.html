七芯合一、推理吞吐提升10倍、每token成本降至黑翅的十分之一，OpenAI、Anthropic、Meta、Mistral AI 联袂背书

Z.ai 发布 GLM-5-Turbo：面向 Agent 工作流的高效低价新选择

202.8K 超长上下文、API 每百万 token 仅 $4.16，定位 OpenClaw 类自主 Agent 场景

中国 AI 创业公司 Z.ai 于3月15日正式发布 GLM-5-Turbo，这是其开源 GLM-5 模型的专有优化版，专为 Agent 驱动的工作流设计，在复杂指令分解、工具调用、定时与持久执行、长任务稳定性方面做了深度优化。该模型通过 OpenRouter 提供 API，上下文窗口约 202.8K token，输出上限 131.1K token，输入定价 $0.96/M，输出定价 $3.20/M，总成本约 $4.16/M，较基础 GLM-5 降低约 $0.04。Z.ai 同时推出 GLM Coding 订阅服务，分 Lite（$27/季）、Pro（$81/季）、Max（$216/季）三档，Pro 用户本月即可优先使用 GLM-5-Turbo。
